# MT Dataset: 多模态光谱-淀粉分子量数据集

## 数据集概述

本数据集来源于论文《SpecKRPI-Net: A Multimodal Spectral Key Region Perception and Interaction Network for Starch Molecular Weight Prediction in Brewing Raw Materials》，用于支持白酒酿造过程中淀粉分子量的定量预测研究。

**数据来源**: 贵州茅台酒股份有限公司

**样本总数**: 460个样本（注：部分文件包含461行，含表头）

**数据类型**: 多模态光谱数据（近红外光谱 + 拉曼光谱）与淀粉分子量标签

**应用场景**:
- 淀粉分子量定量预测
- 多模态光谱融合研究
- 深度学习模型验证
- 酿造过程优化

---

## 数据文件说明

本数据集包含以下5个CSV文件：

| 文件名 | 大小 | 说明 |
|--------|------|------|
| `label.csv` | ~20 KB | 样本标签数据，包含样本ID、分子量及其对数值 |
| `Mw.csv` | ~10 KB | 分子量数据，包含样本ID和分子量值 |
| `NIR.csv` | ~6.4 MB | 近红外光谱数据，包含波长和光谱强度 |
| `RAMAN_1800.csv` | ~7.2 MB | 拉曼光谱数据，包含拉曼位移和强度值 |
| `onehot_knowledge_base.csv` | ~50 KB | 知识库特征，包含样本ID和One-hot编码特征 |

## 数据结构详细描述

### 1. label.csv - 样本标签数据

**文件结构**:
- 列数: 3列
- 行数: 461行（含表头）

**字段说明**:
| 字段名 | 数据类型 | 说明 |
|--------|----------|------|
| `sample_id` | 字符串 | 样本唯一标识符，格式如 "A1-1", "B10-2" |
| `Mw` | 浮点数 | 淀粉分子量（单位：Da），范围约 224-10815 |
| `Mw_log` | 浮点数 | 分子量的对数值，用于模型训练 |

**样本命名规则**:

样本编号格式为"发酵轮次+发酵阶段-窖池号"，例如"A8-1"代表下沙轮次中1号窖的第8个样品。

- **字母（A-H）**: 代表发酵轮次，对应关系如下：

| 字母 | A | B | C | D | E | F | G | H |
|------|---|---|---|---|---|---|---|---|
| 轮次 | 下沙 | 造沙 | 1轮 | 2轮 | 3轮 | 4轮 | 5轮 | 6轮 |

- **字母后的数字**: 代表该轮次中的发酵阶段编号
- **短横后的数字**: 代表窖池编号

**示例**:
```
sample_id,Mw,Mw_log
A1-1,224.16,5.41
B10-2,10815.2,9.29
```

| 分辨率 | 8 cm⁻¹ |
| 扫描次数 | 128次/光谱 |
| 重复测量 | 3次 |
| 样品杯直径 | 5 cm积分球样品杯 |

**数据特点**:
- 高分辨率光谱数据
- 原始数据，未经预处理
- 已归一化到[0,1]范围

### 5. onehot_knowledge_base.csv - 知识库特征

**文件结构**:
- 列数: 约40列（样本ID + 多个特征列）
- 行数: 461行（含表头）

**字段说明**:
| 字段组 | 字段名范围 | 说明 |
|--------|------------|------|
| 样本ID | `sample_id` | 样本唯一标识符，格式为"发酵轮次+发酵阶段-窖池号" |
| 发酵轮次特征 | `fea_0_A` ~ `fea_0_H` | 8个发酵轮次的One-hot编码，A-H分别对应下沙、造沙、1轮、2轮、3轮、4轮、5轮、6轮 |
| 发酵阶段特征 | `fea_1_0` ~ `fea_1_23` | 约24个发酵阶段编号的One-hot编码，对应样本编号中字母后的数字部分 |
| 窖池编号特征 | `fea_2_1` ~ `fea_2_6` | 6个窖池编号的One-hot编码，对应样本编号中短横后的窖池号 |

**特征用途**:
- 作为辅助特征输入模型
- 提供样本的批次、时间等元信息
- 支持知识驱动的预测方法

## 样本信息

### 采样策略

数据集覆盖白酒酿造的完整周期，分为8个酿造轮次：

| 编号 | 轮次名称 | 采样方法 | 采样频率 |
|------|----------|----------|----------|
| A | 下沙 | 混合均匀后取样 | 每轮次1次 |
| B | 造沙 | 混合均匀后取样 | 每轮次1次 |
| C | 1轮 | 混合均匀后取样 | 每轮次1次 |
| D | 2轮 | 混合均匀后取样 | 每轮次1次 |
| E | 3轮 | 混合均匀后取样 | 每轮次1次 |
| F | 4轮 | 窖池中心区域取样 | 每天1次 |
| G | 5轮 | 窖池边缘20cm处深度1米取样 | 第1、3、7、10、14、17、21、30天 |
| H | 6轮 | 酒醅中层(1.4米)和下层(2.8米)取样 | 2次 |

### 批次分布

| 批次 | 轮次1-5 | 轮次6 | 轮次7 | 轮次8 |
|------|---------|-------|-------|-------|
| A | 各1次 | 2-5次 | 8次 | 2次 |
| B | 各1次 | 2-7次 | 8次 | 2次 |
| C-H | 各1次 | 2-6次 | 8次 | 2次 |

### 样本类型

- **高粱原料样品**: 酿造原料
- **发酵醪样品**: 发酵过程中的样品

## 数据预处理方法

### 光谱预处理流程

数据集中的光谱数据已经过以下预处理：

1. **多元散射校正 (MSC)**
   - 目的: 消除固体颗粒大小和有效光程变化引起的散射失真

2. **迭代自适应加权惩罚最小二乘 (airPLS)**
   - 目的: 去除荧光背景噪声
   - 参数: 多项式阶数=1，迭代次数=15，平滑参数λ=100

3. **Savitzky-Golay滤波**
   - 目的: 光谱平滑和去噪
   - 参数: 窗口宽度=100，多项式阶数=5

4. **最小-最大归一化**
   - 目的: 将光谱信号约束到[0,1]范围

### 标签预处理

- 对分子量值进行对数变换
- 目的: 压缩数值尺度，增强模型鲁棒性

## 使用建议

### 数据加载示例（Python）

```python
import pandas as pd
import numpy as np

# 加载标签数据
labels = pd.read_csv('label.csv')
sample_ids = labels['sample_id'].values
mw = labels['Mw'].values
mw_log = labels['Mw_log'].values

# 加载NIR光谱数据
nir_data = pd.read_csv('NIR.csv')
nir_wavelengths = nir_data.columns.values.astype(float)  # 波长值
nir_spectra = nir_data.values  # 光谱强度矩阵

# 加载RAMAN光谱数据
raman_data = pd.read_csv('RAMAN_1800.csv')
raman_shifts = raman_data.columns.values.astype(float)  # 拉曼位移
raman_spectra = raman_data.values  # 强度矩阵

# 加载知识库特征
knowledge_base = pd.read_csv('onehot_knowledge_base.csv')
features = knowledge_base.drop('sample_id', axis=1).values
```

### 模型训练建议

1. **输入特征**:
   - 主输入: NIR光谱 + RAMAN光谱（多模态融合）
   - 辅助输入: 知识库特征（可选）

2. **输出目标**:
   - 推荐使用 `Mw_log`（分子量对数值）作为预测目标
   - 预测结果可通过 `exp()` 转换回原始分子量

3. **数据划分**:
   - 建议使用五折交叉验证
   - 注意保持批次分布的均衡性

4. **模型评估指标**:
   - R²（决定系数）
   - RMSE（均方根误差）
   - RPIQ（四分位距相对预测误差）
   - RPD（预测偏差比）
